2. Root Cause Candidates (Ranked by Technical Likelihood)

Native Request Flooding in RecyclerView 99%

Code: Leaflet_GetTemplateData.java:62 & Leaflet_PosterGroupChildAdapter.java:89

An ad slot is injected every 2 items. The ViewPager preloads 2 tabs eagerly. Opening the screen sends 8–12 requests in 300ms. AdMob's algorithm flags burst traffic and returns ERROR_CODE_NO_FILL (Code 3), causing match rate to drop to 21%.

App Open Eager Preload Abandonment 98%

Code: Leaflet_AppOpenManager.java:158, 215

The instant the user dismisses the splash ad, fetchAd() preloads another ad. But users design a poster and close/kill the app without backgrounding. Every cold start fetches 2 ads but only shows 1, cutting show rate in half (~50%).

Banner 1-Second Viewability Failure 95%

Code: Leaflet_ShareActivity.java:76 & Leaflet_LoadAds.java:22

Banners are only present in 3 secondary screens. ShareActivity is an exit screen where users click WhatsApp or Back within 1–2 seconds. An AdMob impression is only logged after 1 continuous second of screen visibility. The activity finishes before the ad renders.

Active NativeAd Destruction in Memory 95%

Code: Leaflet_NativeAdUtil.java:73-76

The adapter shares a single instance of Leaflet_NativeAdUtil. When item 3's ad loads, it calls this.nativeAd.destroy(), destroying item 0's ad object while item 0 is still visibly rendered on screen! This causes click failures and invalid traffic flags.

public static AdView loadAdmobBannerAd(Activity activity, RelativeLayout mainLayout) {
    if (activity == null || activity.isFinishing() || mainLayout == null) return null;
    mainLayout.removeAllViews();

    String bannerId = new Leaflet_PreferenceClass(activity).getAdsId("BannerAdunitID");
    if (bannerId == null || bannerId.trim().isEmpty()) return null;

    AdView adView = new AdView(activity);
    adView.setAdSize(getAdSize(activity));
    adView.setAdUnitId(bannerId);

    adView.setAdListener(new AdListener() {
        @Override
        public void onAdLoaded() {
            mainLayout.setVisibility(View.VISIBLE);
            Leaflet_AdLogger.logLoaded("Banner", adView.getResponseInfo());
        }
        @Override
        public void onAdImpression() {
            Leaflet_AdLogger.logImpression("Banner"); // Confirmed impression for reconciliation
        }
        @Override
        public void onAdFailedToLoad(@NonNull LoadAdError error) {
            mainLayout.setVisibility(View.GONE);
            Leaflet_AdLogger.logFailedToLoad("Banner", error);
        }
    });

    RelativeLayout.LayoutParams params = new RelativeLayout.LayoutParams(
            RelativeLayout.LayoutParams.WRAP_CONTENT, RelativeLayout.LayoutParams.WRAP_CONTENT);
    params.addRule(RelativeLayout.CENTER_HORIZONTAL);
    mainLayout.addView(adView, params);

    adView.loadAd(new AdRequest.Builder().build());
    return adView; // Return view so Activity can manage lifecycle
}

B. App Open: In-Flight Concurrency Guard

File: app/src/main/java/com/online/flyer/design/postermaker/Leaflet_adManager/Leaflet_AppOpenManager.java

private boolean isLoadingAd = false; // Guard against duplicate in-flight requests

public void fetchAd() {
    if (isAdAvailable() || isLoadingAd) return;

    String adUnitId = preferenceClass.getAdsId("AppOpenID");
    if (adUnitId == null || adUnitId.trim().isEmpty()) return;

    isLoadingAd = true;
    Leaflet_AdLogger.logRequest("AppOpen", adUnitId);

    AppOpenAd.load(myApplication, adUnitId, new AdRequest.Builder().build(),
            AppOpenAd.APP_OPEN_AD_ORIENTATION_PORTRAIT,
            new AppOpenAd.AppOpenAdLoadCallback() {
                @Override
                public void onAdLoaded(@NonNull AppOpenAd ad) {
                    isLoadingAd = false;
                    appOpenAd = ad;
                    loadTime = new Date().getTime();
                    Leaflet_AdLogger.logLoaded("AppOpen", ad.getResponseInfo());
                }
                @Override
                public void onAdFailedToLoad(@NonNull LoadAdError error) {
                    isLoadingAd = false;
                    appOpenAd = null;
                    Leaflet_AdLogger.logFailedToLoad("AppOpen", error);
                }
            });
}

4. Dashboard-to-Logcat Reconciliation Logger

Add Leaflet_AdLogger.java to trace ad stage funnels:

package com.online.flyer.design.postermaker.Leaflet_adManager;

import android.util.Log;
import com.google.android.gms.ads.LoadAdError;
import com.google.android.gms.ads.ResponseInfo;

public class Leaflet_AdLogger {
    private static final String PREFIX = "ADMOB_AUDIT_";

    public static void logRequest(String format, String adUnitId) {
        Log.i(PREFIX + format, "[STAGE: REQUEST] AdUnit: " + adUnitId);
    }
    public static void logLoaded(String format, ResponseInfo info) {
        Log.i(PREFIX + format, "[STAGE: MATCHED/LOADED] Adapter: " + (info != null ? info.getMediationAdapterClassName() : "None"));
    }
    public static void logImpression(String format) {
        Log.i(PREFIX + format, ">>> [STAGE: IMPRESSION_CONFIRMED] <<<");
    }
    public static void logFailedToLoad(String format, LoadAdError err) {
        Log.e(PREFIX + format, "[STAGE: LOAD_FAILED] Code: " + err.getCode() + " Msg: " + err.getMessage());
    }
}
